# Shreya's Bengaluru HR Roles

A daily dashboard for process-oriented HR technology and rewards roles in Bengaluru: HRIS, Workday, SAP SuccessFactors, payroll, compensation and benefits.

The dashboard is published with GitHub Pages. GitHub Actions runs the discovery workflow daily at **8:00 AM India Standard Time** (02:30 UTC). New search results are marked for review; confirm the posting is still active, Bengaluru-based, and a good fit before applying.

## Dashboard

After the Pages workflow finishes, open: https://guneel.github.io/Shreya-hr-roles/

## Application support

Use the filters and status controls to track roles. Status and notes are saved in this browser. Tailor each application around HR systems administration, data quality, configuration, reporting, payroll or compensation cycles, testing/UAT, controls and process improvement.

## Sources and limits

The daily refresh searches publicly indexed results for LinkedIn, Naukri and iimjobs and links to the source. It does not sign into job boards or bypass access controls. Search indexing may miss postings or return stale results, and some pages may require your account to view or apply.
